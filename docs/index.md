# GeneV4

Android Jetpack Compose 组件库。包名 `com.genev4`，公开 API 与 Material3 1.4.0 同名。

```kotlin
implementation("io.github.ctoo-uxd:genev4:0.1.0")
```

| 文档 | 说明 |
|---|---|
| [快速开始]({% link getting-started.md %}) | Maven 坐标、`MaterialTheme`、最小可运行示例 |
| [组件]({% link components/index.md %}) | 按分类的组件索引与用法 |
| [主题]({% link theming.md %}) | 明暗色、品牌色 |
| [从 Material3 迁移]({% link PACKAGE.md %}) | import 对照、不要混用两套 Theme |

源码：[CTOO-UXD/Android-GeneV4](https://github.com/CTOO-UXD/Android-GeneV4)  
API：IDE 悬停组件名，或打开仓库 [`library/.../com/genev4/`](https://github.com/CTOO-UXD/Android-GeneV4/tree/main/library/src/commonMain/kotlin/com/genev4)。真机预览可安装工程里的 `:catalog` 画廊。

{: .note }
仓库 **Settings → Pages** 选择 **Deploy from a branch**，分支 `main`，文件夹 `/docs`，即可发布本站。
